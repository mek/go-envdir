# Security Policy

## Supported Versions

This project is small and maintained on the default branch.

Security fixes, when available, will be made against the latest code on `main`.

## Reporting a Vulnerability

Please do not open a public issue for a suspected security vulnerability.

Instead, report it privately through GitHub's security advisory flow:

<https://github.com/mek/go-envdir/security/advisories/new>

If that route is unavailable, contact the maintainer directly and include:

- a short description of the issue
- the affected version or commit
- reproduction steps or a proof of concept
- any suggested mitigation

I will try to acknowledge reports promptly and provide a remediation plan when the issue is confirmed.
